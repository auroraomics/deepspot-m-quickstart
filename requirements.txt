#

# Nothing here is pinned. These notebooks are written against the packages'
# documented interfaces, and a pin in a quickstart ages into a wrong answer
# about what the current release does. Pin in your own project, not here.

# The client and the local pipeline: open a slide, judge and pack its tiles,
# submit, read the result. A plain install pulls in numpy, h5py, opencv,
# pillow, httpx, pydantic, anndata, tifffile and imagecodecs -- the whole
# documented path, and no deep-learning framework.
#
# Published under its own licence, which is not this repository's MIT:
# https://docs.auroraomics.org/quickstart/#install
auroraomics
